MINI SÚPER EITHAN V7

ACTUALIZACIÓN DESDE V6
1. Descarga Mini_Super_Eithan_V7.zip.
2. En GitHub abre el repositorio Mini-s-per-Eithan.
3. En Code, elimina o reemplaza los archivos de la raíz por los 5 archivos de esta carpeta:
   index.html
   manifest.webmanifest
   sw.js
   icon-192.png
   icon-512.png
4. Haz Commit changes.
5. GitHub Pages seguirá usando main / (root). Espera unos minutos.
6. En iPhone abre tu página y recarga. Si todavía ves V6, entra a Ajustes de la app y pulsa “Forzar actualización V7”.

IMPORTANTE
- La V7 intenta migrar automáticamente los datos guardados con la clave eithan_v6.
- No borres los datos del sitio del iPhone si quieres conservar ventas/inventario guardados localmente.
- La impresión usa la ventana de impresión del navegador. La BT-582 puede requerir que el iPhone/app de impresión acepte el trabajo; esta V7 deja listo el ticket para imprimir/compartir.
